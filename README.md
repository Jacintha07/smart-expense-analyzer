# Smart Expense Analyzer

A beginner Python project that analyzes monthly expenses.

## Features
- Takes expenses as input (name, category, amount)
- Calculates total expense
- Category-wise totals (Food, Travel, Shopping)
- Finds the highest expense
- Gives a spending insight

## Concepts used
Lists, tuples, loops, conditions

## How to run
Open the notebook in Jupyter and run all cells.
